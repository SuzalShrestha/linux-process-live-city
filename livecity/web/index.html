Running without root: other users' processes show as grey “restricted” towers with limited details.
Busiest

    Reading the city

    • Each tower is a process. Height = the Height metric (memory by default, log scale); width = thread count.
    • Glow goes from cool blue glass to hot orange with the Glow metric (CPU by default). Busy towers light more windows and a scanline climbs them faster.
    • Districts group processes by app tree, user, name or state. Roof beacons pulse with disk IO.
    • Green flicker = zombie, violet = stopped, grey = restricted (owned by another user; run with sudo for full detail).
    • New processes rise out of the ground with a flash; exited ones sink away.

    Controls

    • drag orbit · right-drag pan · scroll zoom
    • click inspect a tower · double-click zoom to it
    • / search · F focus selection · P go to parent
    • R reset camera · Space pause · Esc close

    Search syntax

    • chrome — name, command line, user or pid contains
    • user:root name:ssh cmd:--port status:running ppid:1
    • cpu>5 mem>500M threads>=20 fds>100 — terms combine with AND
